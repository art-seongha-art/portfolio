# Moon

3면 CAVE(전면·좌·우 프로젝션)용 실시간 미디어아트. 박성하, 2026.

- 웹 미리보기: `https://art-psh.com/works/moon/` (3면 펼침)
- CAVE 출력: `https://art-psh.com/works/moon/?mode=span` (설치 가이드 참고)

---

## 1. 개요

- 달이 지평선에서 떠올라 정면으로 다가오고, 표면 클로즈업(코페르니쿠스 크레이터)을 거쳐, 달 남극 상공에서 지구가 떠오르는 장면으로 이어진 뒤, 반대편에서 지는 12분 30초 루프입니다.
- 앞쪽 장면은 지구에서 달을 보는 시점이고, 뒤쪽 장면은 달 위에서 지구를 보는 시점입니다.
- 색과 지형은 NASA 달 궤도선(LRO)의 카메라와 레이저 고도계 실측 데이터를 씁니다. 크레이터 위치와 그림자 길이는 실제 지형에서 계산합니다.

## 2. 공간과 방위

- 전면·좌·우 3면 프로젝션 CAVE를 전제로 합니다. 관객 기준점(스윗스팟)에서 원근이 정확하도록, 벽마다 비대칭 원근(off-axis)을 광선추적으로 계산합니다. 그래서 모서리를 지나도 달과 지평선이 꺾이지 않습니다.
- **방위: 정면 = 남쪽, 왼쪽 = 동쪽, 오른쪽 = 서쪽.** 한국에서 남쪽을 보고 서면 달은 **왼쪽(동)에서 떠서 오른쪽(서)으로 집니다.** 서울 위도(37.57°N)에서 실제 달이 그리는 일주 궤적을 계산해 사용합니다. 달은 비스듬히 떠올라 기울어진 채 높아지고, 달의 기울기도 실제처럼 조금씩 돌아갑니다.
- 공간 치수(벽 너비·깊이·높이, 관객 눈높이·위치)는 운영 패널에서 입력합니다. 기본값은 6 × 6 × 3.375 m(16:9)입니다.

## 3. 장면 구성 (12분 30초 반복)

| 시간 | 장면 | 내용 |
|---|---|---|
| 0:00 | 밤 | 운해 위 능선, 흐린 별. 왼쪽 지평선이 밝아짐 |
| 0:30 | 월출 | 왼쪽 벽 능선 뒤에서 달이 떠오름. 초점이 흐린 상태에서 선명해지고, 고도가 오르면서 색이 붉은색 → 노란색 → 흰색으로 바뀜. 얇은 구름 통과 |
| 2:50 | 접근 | 달이 정면으로 이동하며 커짐. 정면 벽을 채운 뒤 양 옆벽까지 확장. 능선과 대기는 아래로 빠짐 |
| 5:20 | 클로즈업 · 코페르니쿠스 | 지름 93km 크레이터 근접. 명암경계선에서 해가 뜨며 크레이터 안으로 빛이 들어오고 그림자가 짧아짐 |
| 7:16 | 전환 | 초점 흐림 + 암전 |
| 7:26 | 남극 · 지구돋이 | 달 남극 상공. 세 벽 아래쪽이 달 표면으로 채워지고, 고도가 올라가며 지평선 너머로 지구가 떠오름. 뒤쪽에서 낮게 드는 햇빛, 긴 그림자 |
| 9:56 | 전환 | 암전 |
| 10:06 | 월몰 | 오른쪽 벽에서 달이 붉어지며 능선 뒤로 짐 |
| 12:00 | 밤 | 처음 상태로 돌아가 반복 |

키보드 `1`–`7`로 각 장면으로 바로 이동할 수 있습니다.

## 4. 극사실 표현 전략

**데이터**
- 색: NASA LRO LROC WAC 컬러 모자이크(2025판, 8K). 바다(현무암)의 푸른 기와 고지대의 갈색 기가 실제 광물 차이를 반영합니다.
- 지형: LRO LOLA 레이저 고도계(전구 64 px/°). 코페르니쿠스 일대와 남극은 약 470 m/픽셀 고해상도 패치를 따로 씁니다.
- 데이터 해상도보다 작은 크레이터는 절차적으로 생성합니다. 실제 달의 크기 분포(N(>D) ∝ D⁻²)를 따르고, 신선도와 깊이에 변화를 주며, 그림자는 해석적으로 계산합니다. 시점 거리에 맞춰 자연스럽게 나타나거나 사라집니다.

**라이팅**
- 반사 모델은 **Lunar-Lambert(McEwen)**입니다. 보름달이 가장자리까지 평평하게 밝은 이유와, 명암경계선의 실제 밝기 변화를 재현합니다.
- 태양 방향으로 지형을 따라가며 **부드러운 그림자**를 계산합니다(태양 시직경 0.53°의 반영 포함). 명암경계선 너머 산봉우리만 빛을 받는 현상도 나타납니다.
- **지구조(earthshine):** 달의 밤쪽이 지구 반사광으로 푸르스름하게 희미하게 보입니다.
- **림라이트:** 달이 능선 뒤에 있을 때 능선 윤곽이 빛나고, 구름 가장자리에 은빛 테두리가 생깁니다(전방 산란).

**대기와 분위기(지구 장면)**
- 고도에 따른 **대기 소광:** 막 떠오른 달은 붉고 어둡고, 높아질수록 노랗다가 은백색이 됩니다. 원반 아래쪽이 위쪽보다 더 붉습니다.
- **대기 굴절**로 지평선 근처의 달이 납작해지고, 지평선 가까이에서 아지랑이처럼 미세하게 일렁입니다.
- **달무리(아우레올)**, 달빛에 물든 하늘, 달이 뜨기 직전 지평선이 밝아오는 빛.
- **운해(雲海)와 겹겹의 능선:** 공기원근과 계곡 안개로 산수화처럼 층을 쌓았습니다. 가까운 봉우리에는 나무 실루엣이 보입니다.
- **실제 별:** HYG 항성 목록의 실제 별을 씁니다. 서울 하늘의 일주운동에 맞춰 달과 함께 돌고, 달빛이 밝아지면 흐려집니다.

**렌즈와 카메라**
- **포커스 풀(아웃포커싱):** 장면이 흐릿하게 나타나고 흐릿하게 사라집니다. 밝은 점은 보케 원반이 됩니다.
- **할레이션과 블룸:** 밝은 달 주변에 필름 같은 따뜻한 번짐이 생깁니다. 달 위 장면에서는 대기가 없으므로 거의 끕니다.
- **비네팅:** 벽마다 따로 걸면 모서리 이음새가 드러납니다. 그래서 공간의 방향 기준으로 계산해 3면에서 끊기지 않게 했습니다.
- ACES 필름 톤매핑, 필름 그레인, 디더링(어두운 하늘의 계단 현상 방지).

## 5. 어지럼 방지 설계

CAVE에서 어지럼은 주로 주변시야 전체가 흐를 때(광류) 생깁니다.

- 카메라 **롤(기울기) 없음**, 지평선은 항상 수평입니다.
- 모든 움직임은 **단조 3차 보간(PCHIP)**으로 가속과 감속이 부드럽고 튀지 않습니다.
- 다가가기는 **로그 거리**로 보간해, 확대 속도가 처음부터 끝까지 일정하게 느껴집니다.
- 표면 드리프트는 초당 약 0.1–0.2°, 가장 빠른 접근 순간에도 주변시야 흐름을 약 1.5°/초 이하로 맞췄습니다.
- 달 표면 → 남극처럼 시점이 크게 바뀌는 곳은 카메라를 움직이지 않습니다. 대신 **초점 흐림 + 암전**으로 넘어갑니다.
- 밝기도 수십 초에 걸쳐 바뀝니다. 깜빡임은 없습니다.
- GPU가 버거우면 프레임을 떨어뜨리는 대신 **해상도를 낮춥니다(동적 해상도).** 끊김이 흐림보다 어지럼을 더 유발하기 때문입니다.

## 6. 기술 구성

- 웹(WebGL2)으로 만들었습니다. 설치 없이 크롬/엣지에서 바로 실행되고, 빌드 과정도 없습니다.
- 한 개의 프래그먼트 셰이더가 픽셀마다 광선을 쏴 달(구 + 높이맵), 지구, 하늘, 구름, 운해, 능선을 계산합니다. 별은 실제 목록을 점으로 그립니다. 마지막 합성 패스에서 초점 흐림, 블룸, 비네팅, 톤매핑, 그레인을 처리합니다.

```
works/moon/
  index.html          작품 페이지(타이틀, HUD, 운영 패널)
  js/main.js          WebGL 초기화, 텍스처 로딩, 렌더 루프, 시계
  js/shaders.js       GLSL: 달·대기·지구·별·합성
  js/timeline.js      장면 연출(키프레임)
  js/scene.js         천문 계산, 달·지구의 자세와 조명 방향
  js/cave.js          CAVE 벽 기하와 출력 레이아웃
  js/ui.js            운영 패널, 단축키
  assets/             NASA 데이터에서 만든 텍스처(약 24MB)
  tools/build_assets.py  원본 NASA 데이터 → 웹 텍스처 변환 스크립트
```

## 7. 설치·운영 가이드

**권장 사양:** 외장 GPU(RTX 3060급 이상 권장, 1080p × 3면 60fps 기준), 출력 3개, Chrome 또는 Edge 최신 버전.

**방법 A — 한 창으로 3면 출력(권장)**
1. 그래픽 드라이버에서 세 프로젝터를 하나의 큰 화면으로 묶습니다(NVIDIA Mosaic / AMD Eyefinity, 예: 5760 × 1080). 순서는 좌 · 정면 · 우입니다.
2. 크롬을 키오스크로 실행합니다.
   ```
   chrome.exe --kiosk --autoplay-policy=no-user-gesture-required "https://art-psh.com/works/moon/?mode=span&q=high"
   ```
3. `P`를 눌러 운영 패널을 열고 공간 치수를 입력합니다. `G`(보정 격자)를 켜고 스윗스팟에 서서, 격자선이 모서리를 지나도 꺾이지 않는지 확인합니다.
4. 프로젝터마다 밝기가 다르면 패널의 '프로젝터 밝기 맞춤'으로 맞춥니다. 설정은 그 PC에 저장됩니다.

**방법 B — 벽마다 창 하나씩**
- `?mode=wall&wall=left`, `?mode=wall&wall=front`, `?mode=wall&wall=right` 창을 각 프로젝터에서 전체화면(`F`)으로 띄웁니다. 운영 패널의 '벽별 창 3개 열기'로 한 번에 열 수도 있습니다.
- CAVE 모드는 **고정 기준 시각에서 흐른 시간**으로 장면을 정하므로, 창이나 PC가 여러 대여도(시계가 맞아 있으면) 같은 장면을 보여줍니다. 한 창에서 일시정지나 이동을 하면 같은 PC의 다른 창도 따라갑니다.

**오프라인 실행:** `works/moon` 폴더를 복사한 뒤 그 안에서 `python -m http.server 8000`을 실행하고 `http://localhost:8000/?mode=span`을 엽니다. 파일을 직접 열면(`file://`) 브라우저 보안 정책 때문에 텍스처가 막힙니다.

**URL 옵션**

| 옵션 | 의미 |
|---|---|
| `mode=preview` · `span` · `wall` · `single` | 3면 펼침 / CAVE 한 창 / 벽 1면 / 일반 화면 |
| `wall=left` · `front` · `right` | `mode=wall`일 때 담당 벽 |
| `q=auto` · `high` · `med` · `low` | 텍스처 품질(high = 8K 컬러) |
| `w`, `d`, `h`, `eye`, `bottom`, `vx`, `vz` | 공간 치수(m): 정면 너비, 측면 길이, 투사 높이, 눈높이, 투사 하단 높이, 관객 위치 |
| `t=초`, `pause`, `speed=배속` | 시작 위치, 멈춤, 배속 |
| `clock=wall` · `free` | 기준 시각 동기화 시계 / 페이지를 연 순간부터 |
| `grid` · `panel` · `ui=0` | 보정 격자 / 패널 열기 / 화면 표시 숨김 |

**단축키:** `Space` 일시정지 · `←` `→` 10초 이동(Shift 1분) · `1`–`7` 장면 · `[` `]` 속도 · `F` 전체화면 · `G` 격자 · `H` 표시 숨김 · `P` 패널

## 8. 확장 아이디어

- **사운드:** 지구 장면은 바람·대기음, 달 장면은 저음 드론 위주(진공이라 소리가 없다는 설정). Web Audio로 같은 시계에 맞춰 생성할 수 있습니다.
- **호흡 센서 연동:** 흉부 밴드나 카메라 기반 호흡 추정값으로 달무리 밝기나 장면 진행 속도를 조절하는 인터랙티브 버전.
- **연구 연계:** CAVE에서 느린 광류 설계가 사이버멀미와 이완에 미치는 영향. 측정 도구로 SSQ(사이버멀미), HRV(심박변이도), STAI(상태불안), IPQ(현존감)를 쓸 수 있고, KCI·A&HCI 논문 소재가 됩니다.
- **변주:** 반복마다 클로즈업 대상(플라톤, 알프스 계곡, 티코)이나 달의 위상을 바꿔 매 회차 다른 장면을 보여줄 수 있습니다.
